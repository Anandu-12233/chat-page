#  Chat Page
 
A clean and simple chat page built with pure HTML and CSS.
 
## Overview
 
This project is a static front-end chat interface — no frameworks, no backend, just HTML and CSS. It's a great starting point for anyone learning web development or looking for a lightweight chat UI to build upon.
 
##  Getting Started
 
No installation or setup required! Just open the file in your browser.
 
```bash
# Clone the repository
git clone https://github.com/Anandu-12233/chat-page.git
 
# Navigate into the project folder
cd chat-page/chat-page
 
# Open index.html in your browser
open index.html
```
 
Or simply download the ZIP from GitHub and open `index.html` directly.
